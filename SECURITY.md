# Security Policy

## Supported versions

This is a community-maintained library. We apply security fixes to the
**latest released version** on Clojars. Upgrade to the latest release before
you report an issue.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Send them privately by email to **jsavyasachi@gmail.com**. You can also use
GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).
Click "Report a vulnerability" on the repository's **Security** tab.

Include this data:

- a description of the issue and its impact,
- the steps to reproduce it, or a proof of concept, and
- the affected version or versions.

We send an initial acknowledgement within a reasonable time. After we confirm
the issue and release a fix, we publish the advisory. The advisory gives
credit to the reporter, unless you ask us not to give credit.
